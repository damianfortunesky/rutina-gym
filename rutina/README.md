# Rutina

Esta carpeta contiene la [rutina de hipertrofia de 4 días durante la rehabilitación del hombro](rutina_rehabilitacion_hombro_4_dias.md).

El programa relaciona el [perfil y las restricciones declaradas](../contexto/perfil_y_objetivos.md) con los criterios de [volumen y frecuencia](../contexto/volumen_frecuencia_hipertrofia.md). No sustituye las indicaciones clínicas ni confirma que los ejercicios sean adecuados para una situación médica particular.

Cada día presenta los ejercicios en orden de ejecución y una fila editable por serie para diferenciar aproximaciones, series efectivas, repeticiones realizadas, carga y observaciones relevantes.
